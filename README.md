# lisboagogo

## 旅行靈感與長期規劃

在 `葡猪.html` 的「我的旅程」清單上方，選擇「旅行靈感・長期規劃」進入 `explore.html`。這是所有旅程之外的共用區域，不隸屬 OSAKA 或其他個別旅程，也不計入旅程數量或排序。

第一版提供世界地圖、月份篩選、現在適合開始準備的建議、活動與年度資料、手動收藏景點、兩人預設的準備草稿，以及依任務日期整理的準備日曆。活動資料的確認狀態與來源分開顯示；研究年份不會自動當成出發年份。

資料預設存於目前瀏覽器。選擇「啟用共用同步」後，使用既有 Firebase 專案的獨立路徑 `travelIdeas/v1`；本機草稿使用 `lisboagogo:travelIdeas:v1`。新頁面不讀寫 `trips`、`tripOrder`、`tripBackups` 或原本憑證資料。這個共用區域不沿用個別旅程的鎖定密碼。

同步以三方合併保留不同欄位的修改；同一欄位衝突時保留本機草稿，讓使用者先下載備份或選擇載入雲端版本。連線或資料庫權限失敗時，介面會顯示狀態並保留本機資料，不將失敗標示成已同步。可下載 JSON 備份；目前尚無備份匯入介面。

準備日曆目前顯示日期，不會發送推播或自動搶票。活動內容為人工整理的起始資料，可在 `assets/explore-data.js` 更新；往年預約資訊不得直接改標為當年已確認。

所有新增檔案都是靜態 HTML/CSS/JavaScript，可使用原本 GitHub Pages 部署方式。既有頁面只有新增入口的 HTML，原本應用程式、同步程式與樣式保持原樣。

驗證：`node --test tests/*.test.cjs`。新增測試涵蓋未知年份、推薦窗口、來源狀態、日曆日期、本機保存、同步隔離、衝突與失敗保留草稿；既有測試涵蓋行程顯示、鎖定與分帳、旅程同步及憑證。
